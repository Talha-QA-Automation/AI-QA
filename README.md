# AI-QA - Playwright Automation

## CRUD API Testing with Playwright + TypeScript

This project contains automated API tests for CRUD operations.

### Tech Stack
- Playwright
- TypeScript
- Node.js

### How to Run
npm install
npx playwright test
npx playwright show-report

### Tests Covered
- POST - Create User
- GET - Get User
- PUT - Update User
- DELETE - Delete User
